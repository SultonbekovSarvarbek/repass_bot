# Картинки Repass

Положите сюда два файла с ровно такими именами:

| Файл | Где используется |
|---|---|
| `repass-description-640x360.png` | Картинка приветствия: бот отправляет её с текстом после `/start` и выбора языка. Также её можно загрузить в @BotFather → Edit Bot → Edit Description Picture. |
| `repass-logo.png` | Аватар бота: загрузите в @BotFather → Edit Bot → Edit Botpic. |

Исходники логотипа — в репозитории лендинга [repass](https://github.com/SultonbekovSarvarbek/repass), папка `brand/`.
`repass-logo.png` сейчас — это `brand/apple-touch-icon.png` (180×180); для аватара бота лучше экспортировать 512×512.

Если картинки приветствия нет, бот просто отправляет приветствие текстом — это не ошибка.
